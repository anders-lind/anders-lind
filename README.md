# MSE in Robot Systems

I recently graduated as Master of Science in Engineering of Robot Systems with specialty in Drones and Autonomous Systems, and on this page you can see some of the projects i have worked on through my studies.

## Plant Pruning Robot

For my master thesis me and my friend created a robot which autonomously prunes rotten leaves from a green wall. It uses color-based vision and AI segmentation to find the leaves, and then a custom designed 3D printed gripper is moved to its location using a Cable Driven Parallel Robot system (CDPR). More details about this project can be found in its own repository at https://github.com/anders-lind/Greenwall-Pruning.

## Autonomous T-Shirt Folding
This project implemented autonomous robot T-shirt folding with a UR5 robot arm and novel landmark detection with SIFT-based correction. More details about this project can be found in its own repository at https://github.com/peterfryd/project_in_robotics_clothing_manipulation/.
